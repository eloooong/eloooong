# Hi, I'm Gelo.

I build web applications with **TypeScript, React, Next.js, and Supabase**. My projects explore public data, listening habits, and practical tools for everyday life.

Currently building **[Rentify](https://github.com/eloooong/rentify-app)**, a peer-to-peer gadget rental marketplace, and developing my work across frontend interfaces, APIs, and databases.

## Selected projects

### [Civica](https://github.com/eloooong/civica-web) · Public data, easier to explore

A web app for exploring Philippine government budgets, legislation, and public datasets. Includes unified search, department comparisons, and links back to the original sources.

**Next.js · TypeScript · Tailwind CSS**

[Explore the app](https://civica-web-two.vercel.app) · [Source code](https://github.com/eloooong/civica-web)

### [SpotiStats](https://github.com/eloooong/spoti) · A closer look at your listening

A personal Spotify dashboard with top artists and tracks, recent listening patterns, library stats, and optional AI insights. Uses Spotify OAuth and a separate Express backend.

**React · TypeScript · Express · Spotify Web API**

[Source code and setup](https://github.com/eloooong/spoti#readme)

### [Rentify](https://github.com/eloooong/rentify-app) · Put idle gadgets to use

A peer-to-peer gadget rental marketplace in **early development**. The foundation includes a responsive app shell, typed Supabase clients, and a database schema with row-level security. Marketplace features are still being built.

**Next.js · TypeScript · Supabase · PostgreSQL**

[Source code and progress](https://github.com/eloooong/rentify-app#readme)
