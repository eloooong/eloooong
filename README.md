## Currently building

### [Rentify](https://github.com/eloooong/rentify-app)

A peer-to-peer gadget rental marketplace: list devices you rarely use, or rent one when you need it.

**Stack:** Next.js · TypeScript · Tailwind CSS · shadcn/ui · Supabase / PostgreSQL

**Stage:** Early development. The responsive app shell, database foundation, and automated checks are in place; the core rental features are still being built.

[Explore the code](https://github.com/eloooong/rentify-app) · [Run it locally](https://github.com/eloooong/rentify-app#local-setup) · [Read the architecture](https://github.com/eloooong/rentify-app/blob/main/docs/architecture.md)
